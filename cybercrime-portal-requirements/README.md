# Cybercrime Portal Requirements Ledger

Drop this folder into the root of the cybercrime portal repository.

## How the AI agent should operate

1. Read `AGENTS.md`.
2. Read `execution/STATUS.md` and `execution/NEXT.md`.
3. Read the relevant requirement files.
4. Inspect the existing codebase.
5. Implement only the current unblocked scope.
6. Test and review.
7. Update `execution/STATUS.md`, `CHANGELOG.md`, and `DECISIONS.md`.
8. Continue to the next unblocked requirement.

The repository is the source of truth.
