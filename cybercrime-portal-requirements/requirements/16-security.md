# 16 — Security

Treat the platform as security-sensitive / critical-service-grade.

## Areas
- zero-trust principles
- MFA
- RBAC/ABAC
- secure sessions
- encryption
- secrets management
- WAF / DDoS controls
- input/output validation
- secure uploads
- malware scanning/sandboxing where appropriate
- immutable audit logs
- monitoring/SIEM integration
- rate limiting / bot defense
- backup and disaster recovery
- secure SDLC
- supply-chain security
- penetration testing
